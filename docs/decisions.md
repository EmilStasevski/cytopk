## 2026-11-06: Toolchain and workspace
- The toolchain is pinned to Rust 1.99.1 (the local stable) in `rust-toolchain.toml`. Edition 2024, `rust-version = 1.85`
  (the MSRV of rand 0.10 / pyo3 0.30, which we will need anyway).
- `Cargo.lock` is committed because the workspace will ship a cdylib and a CLI.
- Crates are added to the workspace when their milestone starts. This avoids empty placeholder crates that need
  fake tests. `members = ["crates/*"]` picks them up automatically.
- Workspace lints: `unsafe_code = forbid`, `missing_docs`, and clippy `unwrap_used`/`expect_used` as warnings,
  which CI turns into errors. Tests may opt out locally with `#![allow(...)]`.
- `[profile.test] opt-level = 2`, so the tests with 1000+ random parameter sets run fast.
