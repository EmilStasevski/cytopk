# Draft: fcsparser's default float32 silently rounds 32-bit integer data above 2^24

*Target: github.com/eyurtsev/fcsparser. Draft only, not posted. All values below are from
`repro_results.json` → `float32`.*

**Versions.** fcsparser 0.2.4, Python 3.12.3, NumPy 1.26.4, pandas 2.2.3.

## Summary

`fcsparser.parse(..., dtype='float32')` is the default. For `$DATATYPE I` with `$PnB 32`, any value above
2^24 = 16,777,216 cannot be stored exactly in float32, and is silently rounded. `dtype='float64'` gives the
exact values. The default loses information without a warning, even though it cannot represent the file's
own data type.

## Minimal file

`files/int32_above_2pow24.fcs` (400 bytes, generated by the cytopk writer) is FCS 3.1, `$DATATYPE I`,
4 × 32 bit, `$PnR 4294967296`, little-endian, 2 events.

```python
import fcsparser
meta, df = fcsparser.parse("int32_above_2pow24.fcs", reformat_meta=True, channel_naming="$PnN")
df.to_numpy()
```

| | event 0 | event 1 |
|---|---|---|
| written (truth) | 0, 16777216, **16777217**, **123456789** | **4294967295**, **16777219**, **33554433**, 1 |
| fcsparser default (float32) | 0, 16777216, **16777216**, **123456792** | **4294967296**, **16777220**, **33554432**, 1 |
| fcsparser `dtype='float64'` | 0, 16777216, 16777217, 123456789 | 4294967295, 16777219, 33554433, 1 |

flowio 1.4.0 and flowCore 2.24.0 return the written values.

Note that 4294967295 (all 32 bits set, inside `$PnR`) becomes 4294967296, which is outside the channel's range.

## Public file

FlowIO test file `data/fcs_files/zero_gain/M0_WM278_S1.fcs` (FlowIO commit 83d28a2, SHA-256
`f9e528334b63fe2f879f06164159a0e1ef5daa0c6e4e253f03c92ad030d6822f`) has 159,190 events × 21 parameters, all
32-bit little-endian integers. **163,890** of its values are above 2^24.

The first such value is event 65, parameter `SORT`, at byte 9701:

- **bytes:** `01 01 00 02`;
- **decoded by hand** (little-endian u32): **33554689**;
- **cytopk and fcsparser `dtype='float64'`:** 33554689;
- **fcsparser default:** **33554688**.

The robustness benchmark found the file-level difference: flowio, FlowKit and flowCore agree with cytopk on
the whole matrix, and fcsparser's default does not.

## Suggested behaviour

For `$DATATYPE I` (or any parameter with `$PnB` > 24), either default to float64, or warn when float32 cannot
hold the values. Applying the `$PnR` bit mask and then checking the maximum would also catch it.
